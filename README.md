Kids' Learning Website
About
This is an interactive kids' learning platform that offers class registration, educational games, quizzes, and progress tracking to enhance the learning experience.

🚀 Features
🏫 Class Registration – Users can sign up for various online classes.
🎮 Interactive Learning Games – Engaging educational games for kids.
📚 Quizzes & Assessments – Self-evaluation tests to track progress.
📊 Progress Dashboard – Monitors learning achievements.
🔐 Secure Authentication – User login and parental controls.
🛠️ Technologies Used
Frontend: HTML, CSS, JavaScript 
Backend: php
Database: sql
